# bchbot — Telegram-бот Business Cup Hackathon

Python 3.12 + aiogram 3, база SQLite, хостинг Railway.

## Роли
- **Админ** — Telegram ID из переменной `ADMIN_IDS`. Назначает модераторов.
- **Модератор** — назначается командой `/addmod ID`.
- **Участник** — все остальные.

## ФотоХант
1. Админ добавляет бота в чат делегатов и пишет там `/setchat` (в чате с темами — внутри нужной темы).
2. OC пишет боту в личку `/task #хэштег текст` — бот публикует задание в чат.
3. Делегаты кидают в чат фото с хэштегом в подписи.
4. Бот присылает фото админу и всем модераторам в личку с кнопками ✅ / ❌.
5. Первое нажатие решает: у остальных сообщение обновляется, делегату бот отвечает в чате.
6. За каждый день, когда у делегата засчитали хотя бы одно фото, — +5 в Экспедицию (день — когда фото прислали).

Чтобы бот видел фото в группе, в @BotFather: `/setprivacy` → выбрать бота → **Disable**
(сделать до добавления бота в группу, иначе удалить и добавить заново). Всем OC нужно нажать `/start` у бота в личке.

## Экспедиция
Игра на весь проект: бот считает сообщения в подключённых чатах.
- любое сообщение (текст, стикер, фото, гиф…) — **1** балл, голосовое или кружок — **3**;
- день с засчитанным фото в ФотоХанте — **+5**;
- не считаются: команды боту, служебные сообщения, OC, боты, сообщения от имени канала,
  сообщения чаще раза в 2 секунды (антиспам);
- лидерборд: `/top` — топ-15, места 1–10 🎁 главные призы, 11–15 — утешительные.
  В личке делегат видит ещё и своё место; OC может отправить `/top` в чат — бот опубликует рейтинг для всех.

**Секретность:** пока Экспедиция не идёт (до старта и на паузе), делегатам `/top` и `/points` не отвечают,
в `/help` и текстах ФотоХанта её нет, сообщения не считаются. Дни ФотоХанта при этом копятся.

Подключение: админ отправляет `/track` в чате или **внутри темы** (например «Флуд») — тогда считается только эта тема.
Бот удаляет команду и присылает подтверждение админу в личку. Открыть игру — `/expstart`, пауза — `/expstop`.
Если включена интеграция с ботом регистрации, баллы получают только активировавшие его.

## Фазы Экспедиции
Баллы между фазами копятся, задания прошлых фаз не ломаются. Объявления и задания бот публикует
в чат фаз (`/setphasechat`; если не задан — в чат ФотоХанта).
- `/phase 1|2|3 [текст]` — начать фазу (открывает Экспедицию, если она была скрыта), `/phase end` — закончить.
- **Фаза 1 — слова.** `/word кофе [баллы] [текст]` — делегат отвечает **reply на пост бота** предложением
  (от 3 слов) со словом; бот проверяет сам (падежи учитываются), ставит 👍. Без reply сообщение заданием не считается.
  Раз на человека за слово, новое слово закрывает старое. По умолчанию +5.
- **Фаза 2 — фото** (отдельно от ФотоХанта). `/photo #тег [баллы] текст` — делегат шлёт фото **с хэштегом
  в подписи** (обязательно), OC проверяет ✅/❌. По умолчанию +10.
- **Фаза 3 — финал**: каркас в `handlers/phase3.py`, механика добавится позже.

## Бинго (офлайн, скрыто от делегатов)
У делегатов нет команд и упоминаний. Админ: `/bingo on` / `/bingo off`, статистика — `/bingo`.
Делегат шлёт боту в личку один альбом ровно из 9 фото (иначе бот просит прислать все 9 заново).
OC получают фото №1–№9 и кнопки ✅ / ❌; ❌ открывает сетку 3×3 — отмечаешь непрошедшие и жмёшь
«Отправить на переработку», делегату приходят номера. Пересдача — снова все 9 фото.
С ботом регистрации сдать могут только отметившиеся на входе. Баллы за бинго — `BINGO_POINTS` (по умолчанию 0).

## Если бот «не видит» сообщения
Telegram по умолчанию включает ботам режим приватности: в группе бот получает только команды и ответы
на свои сообщения — обычные сообщения, кружки и фото с хэштегами не доходят. Решение: **сделать бота админом группы**
(или @BotFather → `/setprivacy` → Disable и перезайти ботом в группу). `/check` показывает, всё ли бот видит;
при запуске бот сам пишет админам, если что-то не так. OC (админ и модераторы) баллы не получают —
на их ответы в заданиях бот отвечает «🧪 Проверка OC».

## Команды
| Команда | Кто | Что делает |
|---|---|---|
| `/start`, `/help`, `/myid`, `/top`, `/points` | все | приветствие, команды, свой ID, лидерборд, свои баллы и место |
| `/task`, `/tasks`, `/close #тег`, `/open #тег`, `/chats`, `/stats`, `/top` в чате | админ, модераторы | ФотоХант, Экспедиция |
| `/setchat`, `/track`, `/untrack` (в группе), `/expstart`, `/expstop`, `/addpoints ID N`, `/addmod ID`, `/delmod ID`, `/mods` | админ | настройка чатов, игры, баллов и модераторов |

## Баллы
Итог = баллы за сообщения (`exp_messages`) + журнал `points_log` (бонусы ФотоХанта `photohunt_day`,
ручные корректировки OC `manual`). Новые механики пишут в `points_log` со своим источником.

## Интеграция с ботом регистрации
Играть могут только участники, активировавшие бота регистрации ([bc2regbot](https://github.com/ewalovespewa-cmyk/bc2regbot)).
Бинго (на проекте) — только отметившиеся на входе. Подробно: [integration/README.md](integration/README.md).

Подключено одной строкой в `main.py` (`await setup_integration(dp)`); код игр не менялся.
Без переменной `BC_API_URL` интеграция выключена и бот работает как раньше.

## Переменные окружения
| Имя | Пример | Описание |
|---|---|---|
| `BOT_TOKEN` | `123:AAH...` | токен от @BotFather (секрет!) |
| `ADMIN_IDS` | `1999072927` | ID админов через запятую |
| `DB_PATH` | `/data/bot.db` | путь к базе; на Railway — на постоянном диске `/data` |
| `EXP_MESSAGE_POINTS`, `EXP_VOICE_POINTS`, `EXP_PHOTOHUNT_DAY_POINTS` | `1`, `3`, `5` | стоимость действий в Экспедиции |
| `EXP_COOLDOWN_SECONDS` | `2` | антиспам: не чаще одного засчитанного сообщения за N секунд |
| `EXP_TOP_SIZE`, `EXP_PRIZE_PLACES` | `15`, `10` | размер лидерборда и мест с главными призами |
| `TZ_OFFSET_HOURS` | `5` | часовой пояс проекта (для «дня» ФотоХанта) |
| `BC_API_URL` | `http://bc2regbot.railway.internal:8080` | адрес бота регистрации; пусто — интеграция выключена |
| `BC_API_TOKEN` | — | = `INTEGRATION_TOKEN` бота регистрации (секрет) |
| `BC_WEBHOOK_SECRET` | — | = `GAMIFICATION_WEBHOOK_SECRET` бота регистрации (секрет) |
| `BC_REG_BOT_USERNAME` | `businesscup2_regbot` | для подсказки «сначала активируй бота участника» |
| `BC_AUTO_APPROVE_JOIN` | `0` | `1` — одобрять заявки в общий чат только активировавшим |
| `PORT` | `8080` | порт приёма событий `POST /bc-events` (Railway задаёт сам) |

## Структура
```
main.py            запуск бота
config.py          настройки из переменных окружения
db.py              база данных
roles.py           роли и фильтры доступа
handlers/common.py команды для всех
handlers/admin.py  команды админа и модераторов
handlers/photohunt.py   ФотоХант
handlers/expedition.py  Экспедиция: подсчёт сообщений и лидерборд
integration/       связь с ботом регистрации: гейт доступа, события, фильтр бинго
tests/             тесты интеграции (pip install -r requirements-dev.txt && pytest)
```

## Локальный запуск
```
pip install -r requirements.txt
cp .env.example .env   # и вписать токен
python main.py
```

Деплой: Railway сам пересобирает бота при каждом push в `main`.
